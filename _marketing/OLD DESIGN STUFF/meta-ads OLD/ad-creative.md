## Visual direction (for the image / static creative)

Hold the Resolve system exactly:
- **Palette:** ink navy `#0A1F44` background or off-white `#FBFBF9`; sage `#1F8B5A`
  (deep `#126142`) as the single accent. No third colour.
- **The one sage dot.** A single sage dot is the brand mark. One per image, never a
  scatter of shapes.
- **Type:** Inter. One short line of text on the image at most, ideally none. Let the
  primary text carry the message.
- **Imagery:** quiet and real. A calm exterior of a modest Peel home, a key on a
  table, soft daylight. Avoid stock "sold" signs, avoid distressed or dramatic
  imagery, avoid anything that reads like a flashy investor "we buy houses" ad.
- **Format:** build each at 1:1 (1080x1080) for feed and 9:16 (1080x1920) for
  Stories/Reels.
- **Restraint test:** if it looks like a loud real-estate flyer, it is wrong. It
  should feel like a steady, trustworthy note, not a pitch.

## Suggested test structure (once live)

Keep the existing Traffic / Link Clicks objective and the Brampton 25km ad set as the
starting frame. Then:

1. **Start narrow.** One ad set, the strongest lane (Power of sale, 1A and 1B as two
   ads), same audience, so the test is creative-vs-creative.
2. **Audience:** Brampton + Peel, 25km radius already set. Age 30 to 65+. No tight
   interest stacking at first; this is a broad-intent problem, let Meta find it.
3. **Budget:** the $20/day already configured is a reasonable test floor. Let it run
   7 days before reading anything, so the numbers are not noise.
4. **What to watch (this is the real "optimization"):** cost per link click, CTR
   (link), and especially what those clicks do on the landing page. A cheap click
   that does not enquire is not a win. Pair this with the site analytics so we judge
   on enquiries, not clicks.
5. **Iterate:** once there is a clear front-runner headline, roll it into the estate
   and divorce lanes. Add lanes one at a time, not all at once.
